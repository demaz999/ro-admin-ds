## Главный вывод по Input и Select

**Предпосылка пивота для этих двух компонентов не подтвердилась.**

Ожидалось: Атом чище, состав наших компонентов в основе атомовский, перенос из Атома дешевле.
Оказалось: по Input и Select **кит 1 существенно богаче составом**, а Атом беднее.

Причина в том, как Атом устроен: **Hover, Pressed и Error у него не варианты, а картинки в
документации.** Состава под ними нет — ни осей, ни слотов. В ките эти состояния подняты в оси
вариантов, то есть формализованы.

| | Атом | Кит 1 |
|---|---|---|
| Input, вариантов | 16 | 20 |
| Input, состояний в оси | `default` / `filled` + `Disabled` | `Default` / `pressed` / `field` / `error` / `disabled` |
| Select, вариантов | 16 | 18 |
| Select, состояний в оси | `default` / `filled`, `Active`, `Disabled` | `Default` / `hovered` / `field` / `pressed` / `edit` / `disabled` |

Взять состав из Атома для Input и Select — значит **потерять** подпись, подсказку, счётчик,
ошибку и нажатие как состояния. Это не мелочь: форма без подписи и подсказки не собирается.

## Что в Атоме есть, а у нас нет

Стоит взять:

| Что | Зачем админке |
|---|---|
| **Встроенный поиск в выпадашке** | длинные справочники без поиска не работают. У нас на его месте пустой слот |
| **`ListGroup` как компонент** | заголовок группы, вложение до 5 групп, gap 8. У нас группы плоские |
| **INSTANCE_SWAP иконки в Select** | у нас в селекте свопа нет вовсе |
| **Текстовые component properties** | `Placeholder`, `Input text`, `Select option` — помогают собирать страницы |
| **Кнопка очистки как именованная часть** | у нас это просто «правая иконка» без роли |

Брать не нужно:

| Что | Почему |
|---|---|
| Size `lanassa` 64px и ось `Rounded` (пилюля r32) | лендинговый и мобильный размер |
| Паттерн `filled` с плавающей подписью внутри поля | съедает высоту и конфликтует с раскладкой `label=left` |
| `Type=map` | условно: карта на пилотной странице есть, но состав узла тот же, отличие только в подложке |

## Что потеряем, если возьмём состав Атома буквально

**Input:** внешнюю подпись с двумя раскладками · строку подсказки с двумя слотами · счётчик ·
`error` как ось · `pressed` как ось · размер 44 · произвольный правый слот со swap.

**Select:** подпись, подсказку, счётчик · состояния `hovered`, `pressed`, `edit` ·
выпадашку внутри варианта · архитектуру `select_container` · компонент `multiselect` (18
вариантов) · `type=loading`.

**Выпадашка:** состояния строки `hover`, `selected`, `hover_selected`, `loading` ·
`group divider` · правую иконку и аватар в строке · ось `size` · нижний слот.
