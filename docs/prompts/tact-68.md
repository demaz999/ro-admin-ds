СБОРКА
1. Field: проп readonly и контекст для вложенных контролов; у каждого из десяти контролов — свой проп readonly
   (работает и без Field) и чтение контекста. Поведение: значение не меняется ни мышью, ни клавиатурой; фокус
   доступен там, где у контрола есть текст значения (выделение, копирование, чтение экранным диктором —
   aria-readonly); у Checkbox, Switch, RadioGroupItem — aria-readonly, переключение отказано, фокус остаётся. Списки
   Select, Autocomplete не открываются. Крестик очистки и слот end у readonly не рисуются.
2. /scheme-edit: в просмотре прошлой версии поля разделов «Настроек» — readonly через Field (или через проп там, где
   Field нет). Раскладка inert — по решению 4.
3. Матрицы: каждый из десяти контролов в трёх состояниях — обычное, readonly, disabled — рядом, со значением.
   Где матрица контрола живёт (/compare или /scheme-edit/states) — там же.
4. Прогон: в СС-11/просмотр и сценариях просмотра версии (СС-45–СС-48 — по факту файла) — шаги «значение
   выделяется» и «правка отказана» для поля ввода, селекта и чекбокса.
