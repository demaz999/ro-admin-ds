**Приоритет** (решение владельца 2026-10-02). HTML-прототипа нет. Вид и структура берутся из макетов. Поведение и
тексты — из `spec-r2.md`. Где спека молчит — берётся макет. Где макет и спека расходятся — действует `spec-r2.md`,
расхождение пишется строкой раздела 11.

**Как сняты числа.** Read-only скриптами Plugin API (`use_figma`) по узлам `figma-nodes.md`: размеры и положение —
`absoluteBoundingBox`, раскладка — `layoutMode`, `itemSpacing`, `padding*`, типографика — `fontSize`, `lineHeight`,
`fontName.style`, экземпляры — `getMainComponentAsync`. `get_metadata` по секции не вызывался: она отдаёт около 1.5 МБ
(ловушка MCP, `CLAUDE.md`). Секция прочитана 2026-10-02: тип `SECTION`, 7 дочерних секций — «Настройки», «Состояния
шапки», «Форма», «Процессы и шаги», «Витрина», «Публикация схемы», «Поиск». В Figma ничего не менялось.

Числа без узла вычислены, формула стоит рядом. Цвета в этом документе не переносятся значениями: вид идёт ролями кита,
значения макета остаются в Figma по node id.

**Макеты собраны из двух слоёв.** Кнопки, поля `input`, `checkbox`, `checkbox_title`, `switch`, `Switcher`,
`column_cell`, `pagination_group`, иконки — экземпляры кита 1. Остальное — фреймы с именами вида `CardBody`,
`RadioCard`, `SimpleChipInput`, `SegmentedControl`, `DetectorRow`, `FieldCard`, `StepRow`, `DiffModal`: мастера у них
нет, источник вида — сам фрейм макета.

**Обезличивание** (решение владельца 2026-10-02). Источники в репо обезличены. В макетах Figma стоят реальные и
несогласованные демо-данные — они не переносятся ни в стенд, ни в этот документ. Стенд — один вымышленный сценарий:
схема «КАСКО — осмотр легкового автомобиля», компания-владелец «Демо Страхование».

### 6.2. Модель — `app/stands/scheme-edit/model.ts`

Один модуль. Данные стартуют из `app/stands/scheme-edit/demo-data.json` — вымышленный сценарий раздела 1.

| Часть | Содержимое |
|---|---|
| конфигурация схемы | один тип `SchemeConfig`: настройки по семи разделам, форма (группы, поля), процессы (процессы, шаги), витрина |
| версии | `snapshots` — неизменяемые снимки `{ id, publishedAt, author, inspections, config }`; `current` — последний снимок; `draft` — конфигурация с автором и временем последней правки |
| дифф | чистая функция `diff(a, b)`: сводка по четырём областям (Настройки · Форма · Процессы · Витрина), группы «Добавлено · Изменено · Удалено», список «Требует внимания», следствия по матрице правил; один расчёт на оба режима — черновик против current и версия N против N−1 |
| валидация | `validate(config)`: предупреждения с признаком «критично» |
| зависимости | матрица правил: «гасит» (причина недоступности) и «вооружает» (счётчик и адрес перехода) |
| поиск | индекс «ключ · подпись · синонимы · описание · путь» по всем табам; `search(q)` отдаёт результаты с путём |
| автосохранение | реактивное поле `save`: `saving` → `saved` либо `error`; таймер; `retry()` |
| операции | правка настройки, добавление и удаление поля, группы, процесса, шага, шаблона; массовые операции; `publish()`, `resetDraft()`, `copy()`; история отмены для toast «Отменить» |
| просмотр снимка | `viewing` — id открытого снимка; пока он задан, операции правки отказывают |
| состояние интерфейса | таб, раздел, якорь, открытая поверхность (сайд, модалка, оверлей и их стек), выделение полей и шагов, запрос поиска, флаг закрытой плашки, presence |

**Границы — как у `free-shoot.md`, 16.2.** Модуль не знает DOM и компонентов. Отказы и подтверждения он отдаёт
очередью уведомлений с текстами спеки. Страница переводит модель в пропы компонентов, события компонентов — в
операции модели; прокрутка к якорю, фокус и подсветка найденного — страница. Оснастка адреса выставляет состояние
модели.

Сайд держит собственный черновик сущности: «Сохранить» отдаёт его модели одной операцией, «Отмена» отбрасывает.
Полотно пишет в модель сразу.
