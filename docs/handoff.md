## Где мы находимся

Волна 0 собрана и пересобрана по протоколу переноса. Затем поступил **пивот источника**:
кит 1 исторически является кастомизацией дизайн-системы Росатома («Атом»), и была гипотеза, что
состав компонентов дешевле брать из оригинала Атома, а не из кита 1.

**Этап 0 пивота — разведка — завершён.** Отчёт: [atom-audit.md](atom-audit.md).

**Решения по пивоту ещё нет.** Михаил передаст его новой сессии отдельным заданием.
До этого момента ничего не пересобирать и ветку `atom-base` не создавать.

## Что показала разведка — коротко

Сравнивался **только состав** (структура, оси, состояния, слоты, геометрия), не цвет.

**Предпосылка пивота не подтвердилась.** Кит 1 оказался не кастомизацией Атома, а параллельной
системой: по Input, Select, Tabs, Badge и Chip у кита **больше** состава, а не меньше.

Причина структурная: у Атома Hover, Pressed и Error — картинки в документации, а не варианты
компонента. Кит эти состояния формализовал в оси и добавил подпись, подсказку и счётчик, которых
в Атоме нет вовсе.

**Предложение, вынесенное в отчёт:** забирать из Атома **оси, а не геометрию**.

**Иконки** — единственный раздел, где пивот сработал, но иначе: библиотека Атома физически
недоступна, зато кит уже примерно на 85% состоит из Material Symbols. Замена превращается в
переименование.

Полная карта «компонент → источник состава» — в конце `atom-audit.md`.

## Как проверить, что всё живо

```bash
npm install && npm run dev
```

Витрина — `http://localhost:3000`, наложение на эталоны — `http://localhost:3000/compare`.

На `/compare` есть раздел «Автопроверка шрифтов»: обходит текстовые узлы внутри `[data-slot]` и
помечает ошибкой любое семейство не из темы и любой кегль вне шкалы кита. Если после правок он
показывает провалы — что-то отвалилось.

> Node ставился в эту систему заново. Если `npm` не находится, PATH нужно подтянуть из машинных
> переменных: Node лежит в `C:\Program Files\nodejs`.
