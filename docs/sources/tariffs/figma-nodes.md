- `get_metadata` по секции `30824:1416` — ловушка размера из `CLAUDE.md` (секция 40 105 × 1 760, десятки кадров 1440).

- В макетах стоят экземпляры кита 1 (`btn_accent` и другие). Провенанс вида — мастер кита 1 по `docs/kit-inventory.md`;
  экземпляр в макете указывает, какой мастер искать.

- У каждого кадра в секции есть подпись-описание (текстовые узлы над кадрами) — это пояснения дизайнера, не тексты
  интерфейса.
