# Журнал оркестратора

Режим оркестратора — правило 24 `docs/chat-protocol.md`, роль — `docs/orchestrator.md`. Журнал ведёт оркестратор;
владелец читает его на приёмке глазом вместе с реестром расхождений `docs/scheme-edit.md`, раздел 11.

## Для владельца

Вход приёмки. Пункты по порядку важности; закрытый пункт остаётся с пометкой «закрыт тактом N».

### Ждут людей

  До ответа элементы не выводятся (строки 35–37 реестра расхождений).

  версии, стратегия конкурентного черновика. Сборке страницы не мешает: модель стенда работает на демо-данных.
