# Архив: компоненты на составах кита 1

**Это не мёртвый код и не черновик.** Здесь лежит волна 0 целиком — шесть компонентов,
собранных строго по протоколу переноса от мастеров кита 1, с эталонами и страницей наложения.
Они работали и совпадали с макетами.

## Почему они здесь

Решением от 2026-08-12 источник состава сменился: основа кита 2 переносится из **дизайн-системы
Атом**, а не из кита 1. Гибрид «оси из Атома, геометрия из кита» был рассмотрен и отклонён.

Кит 1 при этом не признан ошибкой. Разведка (`docs/atom-audit.md`, этап 0) показала обратное: по
составу кит 1 **богаче** Атома — у него больше состояний в осях, есть подпись, подсказка и
счётчик, которых у Атома нет вовсе.

Поэтому код не удаляется, а откладывается.

## Когда это достаётся обратно

**В фазе обогащения** — после того как Михаил примет атомовскую основу.

Порядок обратный переносу: атомовское ядро остаётся ядром, наши расширения надстраиваются над ним
по одному, с эталонами из кита 1. Конкретно возвращаются:

| Что | Из какого файла |
|---|---|
| подпись, подсказка, счётчик у полей | `ui/input`, `ui/select/SelectField.vue` |
| состояния `error` и `pressed` как оси | `ui/input`, `ui/select` |
| два иконочных слота и пятое состояние `not_active` у кнопки | `ui/button` |
| `Chip` и `StatusBadge` — сущности, которых в Атоме нет | `ui/status-badge` |
| два несводимых вида вкладок: рельс и таблетка | `ui/tabs` |

Пилотная страница «Мои осмотры» собирается **после** обогащения: на голых атомовских ядрах она не
собирается, это известно и нормально.

## Что внутри

| Папка | Что |
|---|---|
| `ui/` | шесть компонентов: `badge`, `button`, `input`, `select`, `status-badge`, `tabs`. Код целиком, вместе с комментариями-провенансом на каждом значении |
| `reference/` | эталоны — экспорт мастеров кита 1 1x по node id. Лежали в `public/compare/kit` |
| `pages/index.vue` | витрина волны 0: компоненты в состояниях default, hover, focus, disabled, error |
| `pages/compare.vue` | страница наложения на эталоны кита 1, с покоординатной вырезкой вариантов |

## Как это отключено

Компоненты вынесены из `app/components/ui`, поэтому Nuxt их больше не автоимпортирует и в сборку
они не попадают. Реестра (`registry.json`) на момент архивации ещё не было — отключать в нём
нечего.

Страницы скопированы, а не перенесены: живые `app/pages/index.vue` и `app/pages/compare.vue`
продолжают работать, из них убраны разделы кита 1.

**Тема не архивируется.** 78 токенов, 11 текстовых стилей и PT Root UI остаются рабочими и общими
для обеих основ — они перенесены из кита 1, но от состава компонентов не зависят.

## Как достать

Файлы самодостаточны: вернуть папку в `app/components/ui` — и компонент снова автоимпортируется.
Единственная внешняя зависимость — `IconPlaceholder.vue`, он лежит здесь же, рядом.

`IconPlaceholder` переехал сюда, когда появился настоящий `Icon` на Material Symbols: в живом
коде он больше не используется, а компонентам кита 1 ещё нужен. При возврате из архива его
уместнее заменить на `Icon`, а не тащить обратно.

Node id мастеров кита 1 — в `docs/kit-inventory.md`, разбор волны 0 — в `docs/waves.md`.
