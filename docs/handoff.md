## Известные хвосты

- **Тема `atom` неполна намеренно.** В неё попадает только то, что показал мастер очередного
  перенесённого компонента; остальные роли наследуются от rososmotr. Будет расти по волнам.
- **Тема `viewapp` пуста**: каркас с TODO, значений нет и не выдумываются.
- **`PopOverList` и `ScrollBar`** помечены авторами Атома как «Not DS», но без них не собирается
  `Select` — вопрос 25.
- **Модального окна как компонента в Атоме нет** — только композиции из инстансов. Строка в
  `design-debt.md`, закрытие на этапе 2.

## Как проверить, что всё живо

```bash
npm install && npm run dev
```

Витрина — `http://localhost:3000`, наложение — `http://localhost:3000/compare`.

На витрине переключатель тем. `/compare` идёт в теме `atom` целиком: родные цвета и гарнитура
эталона, иначе расхождение состава путается с расхождением цвета.

Раздел «Автопроверка шрифтов» на `/compare` обходит текстовые узлы внутри `[data-slot]` и
проверяет computed-семейство и кегль. Он знает про `data-theme` и про контролы, у которых текст
лежит в атрибуте. Сейчас показывает 48 проверенных узлов и ноль провалов — если после правок
появятся провалы или счётчик упадёт в ноль, что-то отвалилось.

> Node лежит в `C:\Program Files\nodejs`. Если dev-сервер уже поднят с прошлой сессии, он держит
> файлы: `git mv` по `app/components` упадёт с «Permission denied», а автоимпорт не увидит новых
> папок. Перезапуск сервера лечит и то, и другое.
