# Журнал передач фронтам

Версии передачи кита фронтам — правило 23 `docs/chat-protocol.md`. Версия — git-метка `handover-ГГГГ-ММ-ДД`: фронты берут
компоненты по метке; метка ставится по закрытию экрана; выпущенная передача задним числом не меняется.

Три раздела у каждой версии: **«Добавлено»** — новые компоненты, варианты, пропы, слоты: существующие вызовы не меняются;
**«Исправлено»** — дефекты поведения и доступности без изменения вида; **«Меняет существующее»** — видимое изменение у уже
стоящих вызовов. Строки написаны на языке вида и поведения: код компонентов у фронтов свой, кит — образец; API — справкой.

### Исправлено

- **Button.** Классы варианта и размера сливаются через `cn`: поля варианта перекрывают поля размера. У вариантов `default`, `secondary`, `destructive` вид прежний.
- **Select.** Триггер получает фокус с клавиатуры (`tabindex="0"`): выбор открывается по Tab и Enter.
- **Select.** `SelectContent` несёт `z-50`: список внутри модального окна ложится поверх окна.
- **Checkbox.** Состояние `indeterminate` доходит до контрола: `aria-checked="mixed"`, клик из него отмечает флажок (`update:modelValue` — `true`). Вид прежний.

### Меняет существующее

- **Button.** У залитых вариантов `default`, `secondary`, `destructive` кольцо фокуса с клавиатуры отступает от кнопки на 2 цветом фона (`ring-offset-2`). В покое и под мышью вид прежний.
- **IconButton.** У варианта `default` кольцо фокуса с клавиатуры отступает от кнопки на 2 цветом фона. Остальные варианты и покой — прежние.
- **Tabs.** Вид `line` выглядит как VaTabs (va-ui 0.2.0): вкладка 44, поля 0 16, 15/20 bold `--foreground-secondary`, нижняя граница 1 `--border` у каждой вкладки; активная — `--foreground` над подложкой `--background` с радиусом 8 8 0 0 и полосой 2 `--primary`, переезд 0.16 с. Было: линия 4 под текстом активной вкладки.
- **Input.** При `placeholder=""` значение стоит по центру поля по вертикали: строка плавающей подписи не резервируется, каретка пустого поля при фокусе не прыгает. С непустым `placeholder` — прежнее.
- **Select.** При `placeholder=""` выбранное значение стоит по центру поля по вертикали, как у `Input`. С непустым `placeholder` — прежнее.
- **Select.** Заголовок `SelectGroup` — по высоте текста с полем 8 сверху, зазор до списка 2 (было: высота 32 и зазор 8): от текста заголовка до текста первого двухстрочного пункта — 12. Отделение групп линией — прежнее.
- **Checkbox.** Зазор от флажка до подписи — 8 (было 12): флажок с подписью уже на 4. Тот же зазор — у всего семейства выбора: `RadioGroupItem` и `Switch` (в передачу 2026-09-30 не входили).
- **Checkbox.** Без подписи (нет слота и `subtitle`) выводится только контрол: компонент занимает 16 вместо 28 по ширине и встаёт по центру отведённого места. С подписью — прежний.

Без итогового изменения: глиф `fullscreen` у `Icon` — правка такта 51 (оптический размер 20) отменена тактом 52, контур тот же,
что в передаче 2026-09-30. `ButtonArrow`, `Badge`, `Tooltip`, `Image`, `Popover` после передачи не менялись.
